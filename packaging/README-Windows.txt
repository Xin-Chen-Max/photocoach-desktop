PhotoCoach for Windows 64-bit

Extract the complete ZIP to a folder, then run PhotoCoach.exe inside PhotoCoach.
Keep the _internal folder beside the executable. Python is included.
Windows 10/11 AMD64 is the target; ARM64 and 32-bit Windows are not supported.

The executable is unsigned. No installer or administrator access is required.
Original Sony ARW and Nikon NEF photos remain separate and read-only.
Use Save to save a PhotoCoach project; use Export for a JPEG or 16-bit TIFF.
Inspect sharpening and noise reduction at 100%. Fit naturally hides fine detail.
Spatial previews now use native pixel radii before display reduction. Fit edits
with active sharpening/NR can update more slowly than plain tonal controls.

The default photo editor runs locally. Cloud coaching requires manual setup and
explicit sending. Local AI needs a separate Ollama engine and model download;
neither Ollama nor model weights are included in this ZIP.
Settings and model downloads are stored outside this application folder.
